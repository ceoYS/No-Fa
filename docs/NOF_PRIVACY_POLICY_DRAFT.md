# NoF 실드 개인정보 처리 방침 (초안)

> Draft only. RC-15 pre-submit hardening artifact. This is the text intended to be hosted
> at a public URL before a Chrome Web Store submission. **공개 URL 호스팅은 아직 남은 작업이에요** —
> 이 문서는 초안이고, 실제 제출 전에 공개 페이지로 올려 스토어 리스팅에 링크해야 한다.

## 1. 무엇을 수집하나

**아무것도 수집하지 않아요.** NoF 실드는 온디바이스 전용이에요. 방문 기록·주소·검색어를
수집하지 않고, 어떤 서버로도 보내지 않아요. 네트워크 호출, 원격 코드(CDN), 외부 API,
애널리틱스가 없어요.

## 2. 막은 대상을 저장하나

저장하지 않아요. 멈춤 페이지(`blocked.html`)는 어디로 가려 했는지 읽지도, 저장하지도,
표시하지도 않아요. 앱으로 돌아가는 딥링크는 `from=shield` 와 거친 목적지(`to=record|urge`)만
담고, 막은 주소·검색어는 절대 넘기지 않아요.

## 3. 앱 → 확장으로 오가는 데이터

NoF 웹앱은 사용자가 **직접 확인한 구체 값**만 `SET_BLOCK_RULES` 로 보내요. 앱의
**상황 메모는 브라우저 규칙으로 보내지 않아요** — 그 자체로는 차단 토큰이 되지 못해요.
확장은 그 값으로 Chrome `declarativeNetRequest` 동적 규칙을 만들어, 일치하는 최상위
내비게이션을 NoF 잠깐 멈춤 페이지로 이어줄 뿐이에요.

## 4. 데이터 판매·공유

**데이터를 팔지 않아요.** 광고도, 제3자 공유도 없어요. 수집 자체가 없으니 팔 데이터도 없어요.

## 5. 권한

`declarativeNetRequest` 하나만 써요. 브라우징을 읽거나 스크립트를 주입하지 않고, 쿠키·기록·
탭에 접근하지 않아요. 최소 권한이에요.

## 6. 한계 (정직)

- **이 Chrome 브라우저에서만** 작동해요. **기기 전체·다른 앱·모바일은 막지 않아요.**
- 위험한 주소를 스스로 분류하거나 큐레이션하지 않아요 — 무엇을 멈출지는 사용자가 정해요.
- 마찰이지 벽이 아니에요. 시크릿 창·다른 브라우저·확장 끄기로 우회할 수 있어요.
- **의학적 치료나 진단이 아니에요.** 자기조절을 돕는 보조 도구일 뿐이에요.

## 7. 문의

이 초안은 RC-15 단계 산출물이에요. 실제 제출 전 공개 URL·연락처·발효일을 채워야 해요.
