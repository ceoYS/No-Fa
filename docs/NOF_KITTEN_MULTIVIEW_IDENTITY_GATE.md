# NOF_KITTEN_MULTIVIEW_IDENTITY_GATE.md

생성된 multi-view reference pack(8장)의 **identity 검수표**.
`docs/prompts/NOF_KITTEN_MULTIVIEW_GENERATION_PROMPT.md`로 생성한 이미지에만 적용한다.
기준 원본은 항상 `public/assets/pets/white_kitten_main.webp` — 검수는 원본을 옆에 띄워 놓고 한다.

**규칙: 8장 전부, 13항 전부 1이 되기 전에는 image-to-3D 단계로 넘어가지 않는다.**
점수 합산이 아니라 전항 통과제다 — 12/13은 불합격이다.

## 검수 방법

1. 원본(`white_kitten_main.webp`)과 대상 이미지를 나란히 놓는다.
2. 첫 질문은 항상 **"이것은 그 고양이인가?"** — 예/아니오가 3초 안에 "예"가 아니면 이미 실패다.
3. 아래 13항을 이미지마다 0(불일치) / 1(일치)로 기록한다.

## 즉시 불합격 조건 (한 항목이라도 해당하면 그 이미지는 재생성)

- 13항 중 **한 항목이라도 크게 다름**
- **측면(03/04)에서 주둥이가 개처럼 길어짐** — 이 파이프라인의 최대 실패 유형
- **후면(05)·rear ¾(06)에서 성묘 체형으로 변함** (몸이 길어지거나 날씬해짐)
- **view마다 눈·귀·체형이 달라짐** — 같은 개체가 아니라 8마리의 비슷한 고양이
- **털이 플라스틱/도자기처럼 보임** (잔털 질감 상실)
- 목걸이·리본·무늬·소품이 생김
- 입이 열리거나 표정이 변함 (neutral calm 이탈)
- pose·scale이 다른 view와 어긋남 (multi-view 3D 입력으로 사용 불가)

## 기록 규칙

- 검수 결과는 이 표를 복사해 `Downloads/NoF-kitten-multiview-input/generated/GATE_RESULT_<날짜>.md`로 저장.
- 불합격 이미지는 삭제하지 말고 `generated/rejected/`로 이동 (실패 유형 학습용).
- 8장 전부 통과 → `docs/NOF_KITTEN_IMAGE_TO_3D_HANDOFF.md`의 입력 조건 충족.

## 이 게이트가 지키는 것

3D 생성기는 입력 이미지들이 같은 개체라고 **가정**하고 형상을 융합한다.
view 간 identity가 흔들린 입력을 넣으면 그 오류가 3D geometry에 영구히 구워진다 —
게이트를 3D 생성 **앞**에 두는 이유다. 기능이 아니라 identity가 판정 기준이며,
이는 `ASSET_CONTRACT.md §6.5`의 "identity가 다르면 기술 요구를 만족해도 불합격"과 같은 원칙이다.
