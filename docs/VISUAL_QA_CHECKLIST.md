# NoF 비주얼 QA 체크리스트 (VISUAL_QA_CHECKLIST)

작성일: 2026-06-10 · 용도: UI를 바꾼 **모든** 라운드에서 머지 전 실행하는 눈-검증 절차.
원칙: 정적 가드(`npm run check:nof`)는 불변식을 증명할 뿐, 화면이 *그렇게 보이는지*는 증명하지 못한다 (R-1 죽은 소리 토글이 산 증거 — 가드 PASS인데 런타임 위반). 빌드·가드 PASS 후에도 이 체크리스트 전이 끝나야 "확인됨"이라 말한다. 브라우저를 못 띄웠으면 **"비주얼 QA 미검증"이라고 그대로 적는다.**

표기: `[ ]` 미확인 / `[x]` 통과 / `[!]` 발견(리뷰 문서에 R-번호로 등록)

---

## 0. 공통 절차 (모든 화면 공통 선행)

- [ ] `npm run dev` 기동, headless/실브라우저에서 390×844 뷰포트로 열기
- [ ] 한글 폰트 실제 로드 확인 (□ 토푸가 보이면 환경 문제부터 기록 — CDN 차단/로컬 폰트 부재)
- [ ] 콘솔 에러 0건 (외부 리소스 실패는 별도 기록 — R-9 추적)
- [ ] 화면당 스크린샷 저장: `references/visual-qa/<YYYY-MM-DD>/qa-NN-<screen>.png`
- [ ] 탭 가능해 *보이는* 모든 요소를 실제로 탭 — 반응 없는 요소 발견 시 `[!]`
- [ ] 보이는 모든 문장을 소리 내 읽기 — 수치심/단정/내부 어휘(P0·MVP·프로토타입·enum)/현재형 차단 클레임 발견 시 `[!]`

## 1. 홈 / 다중 카운터

- [ ] 타이머 히어로가 첫 화면 최상단 (스크롤 0에서 일·시:분:초 모두 가시)
- [ ] 초가 실제로 흐름 (5초 관찰)
- [ ] 카운터 카드 ≥2개 노출, 각 카드에 목표·최장·연결 규율 수
- [ ] 카드 탭 → 히어로 즉시 교체 + 선택 표시(테두리)·`aria-pressed` 변화, "보는 중" 텍스트 배지 없음
- [ ] 카운터명에 금지·제한 어휘 없음 (시드 포함 — R-2 재발 감시)
- [ ] 위기 CTA("못 참을 것 같아요")가 주황 1순위, 경쟁 CTA 없음
- [ ] 재시작("무너졌어요") 탭 → 확인 시트 선행 (즉시 리셋 아님), 시트 Esc/딤 닫기
- [ ] 재시작 확정 → **선택된 카운터만** 0으로, 다른 카운터 무변화
- [ ] 동행 티저 카드 존재 + 비기능·고정 카피 + 랭킹/등수/점수 어휘 0건 (R-4 이후)
- [ ] 연결 규율 카드: 상태 라벨 3종만, 시간 표기 없음
- [ ] 방 온기 라벨이 실제 분기 수와 일치 (R-11)

## 2. 규율 (나의 규율)

- [ ] 머리 문장에 무징벌 프레이밍 잔존 ("벌주기 위한 약속이 아니라…")
- [ ] 카운터 필터 칩 동작 (전체/카운터별 그룹 전환)
- [ ] 상태 변경: 규율 탭 → 3상태 시트 (지켰어요/위기였지만 버텼어요/못 지켰어요), `해당 없음` 류 없음
- [ ] "위기였지만 버텼어요" 선택 시 성취 카피 표시
- [ ] "못 지켰어요" 선택 → 타이머 무변화 + 가벼운 복기 제안(강제 아님)
- [ ] 규율 추가 시트: 예시 placeholder + 카테고리 칩 + 직접 입력 + 카운터 연결 칩 + "새 카운터도 함께 만들기" + "연결 안 함"
- [ ] 삭제 버튼/스와이프 삭제 어디에도 없음 (보호 규칙 #8)
- [ ] 배지(복기 완료 등)는 표시 전용 — 탭해도 상태 안 바뀜이 명확

## 3. 펫 룸 (고양이 방)

- [ ] 고양이가 장면에 항상 보임 (스크롤 0에서)
- [ ] 장면 정직 고지 노출 ("완성된 방 이미지로 표시 중… 배치 기능은 투명 아이템 이미지가 준비되면")
- [ ] "아이템 배치 계획 (준비 중)" 라벨 — 드래그 시도 시 아무것도 안 끌림
- [ ] 간식 주기: 카운트 감소 + hand-off 연출(잔불 입자) + "놓아두었어요" 계열 카피, "먹었어요" 0건
- [ ] 간식 0개일 때 버튼이 시각적으로 비활성 + 얻는 방법 안내
- [ ] **소리/무음 토글: 사운드 파일이 실제 존재할 때만 보임** — dev 서버(파일 없음)에서 토글이 보이면 즉시 `[!]` (R-1 회귀)
- [ ] 고양이 반응 카피가 모션·행동 단정 없음 (관찰·방 상태 화법만)
- [ ] 보상 면책 문구 노출 ("절제를 대신하지 않아요")
- [ ] 시트(보관함/상점) 바텀 앵커 + Esc + 딤 닫기 (R-5 이후)

## 4. 체크인 (1분 기록)

- [ ] 첫 문장에 프라이버시 선언 ("밖으로 공유되지 않아요")
- [ ] 모든 입력이 선택형 — 필수 자유 텍스트 0개
- [ ] 칩 선택 즉시 시각 피드백 + `aria-pressed`
- [ ] "특별히 없음"이 다른 트리거와 상호 배타로 동작
- [ ] 다음 버튼: 입력 전 비활성이 *보이게* 비활성
- [ ] step2 규율 점검: 3상태만, 규율 6개 기준 한 화면에서 과반 가시 (R-7 이후)
- [ ] 완료 시 적립 안내 1회 — 같은 날 재완료 시 중복 적립 없음
- [ ] 이모지 글리프 실기기 렌더 확인 (4개 이하 유지)

## 5. 기록 / 캘린더 (최근 기록)

- [ ] 화면명이 기능명 ("최근 기록"/"절제 기록") — 메타포 단독 제목 아님
- [ ] 기간 칩(7/14/30/이번 달) 전환 동작 + 선택 표시
- [ ] 점 범례 ≤4종, 어휘는 PRD C2 결정본과 일치 (R-14 결정 전엔 현행 유지 확인만)
- [ ] **빨간색·X·실패 어휘 0건** — 재시작일도 따뜻한 톤
- [ ] 날짜 탭 → 상세 시트: 절제 상태·규율 집계·계기 칩·복기 인용·다음 행동·배지
- [ ] 기록 없는 날 탭 → 차분한 빈 상태 (오류·공백 아님)
- [ ] 시트 닫기 3경로 (버튼/Esc/딤)

## 6. 보상 / 상점

- [ ] 적립 경로 설명 가시 (어떤 절제 행동 → 몇 조각)
- [ ] 마일스톤: 받을 수 있는 것만 "받기" 활성, 잠긴 것은 사유 카피 ("오늘을 채우면 열려요")
- [ ] 같은 마일스톤 2회 수령 불가 (받기 → 받음 상태 전환)
- [ ] 상점 품목 전부 고정가·비확률 — 확률/뽑기/랜덤 어휘 0건
- [ ] 스트릭 복구·기록 삭제 류 상품 없음
- [ ] 재발 직후 동선에 상점 진입 강조 없음
- [ ] 가격·재화 표기 차분 ("지금 사야" 류 압박 0건)

## 7. 재발/회복 상태 (무너졌어요 → 복기)

- [ ] 재발 진입은 항상 확인 단계 경유
- [ ] 재발 후: 해당 카운터만 리셋 + 이전 기록 보존 표시
- [ ] 복기 화면: 3문항(왜/계기/다음 행동) + 계기 enum 칩 + "한두 줄이면 충분해요"
- [ ] 재발 복기는 "왜" 필수 / 슬립 복기는 전부 선택 — 무게 차등 확인
- [ ] 탈출구("조금 이따 할게요") 존재·동작
- [ ] 완료 후 배지 반영 (복기 완료 등) + 같은 날 중복 적립 없음
- [ ] 전 구간 수치심·실패자·벌점 어휘 0건, 펫 처벌 묘사 0건
- [ ] 잠깐 멈춤: 바텀 내비 중앙에서 1탭 진입, 5:00 타이머 실동작, 대체 활동 패널 실존, 닫기 항상 가능

## 8. NoF 실드 정직성

- [ ] 상태 pill "준비 중" + "아직 실제 차단은 제공하지 않아요" 가시
- [ ] **켜기/끄기 토글 없음** + 무토글 사유 카피 잔존
- [ ] 현재형 차단 클레임("막고 있어요/차단했어요") 전 화면 0건
- [ ] 신호 입력: 추상 4종 칩만, 주소/도메인/URL/링크 어휘 0건
- [ ] "위험한 사이트를 직접 찾아 적지 마세요" 상시 가시
- [ ] 신호 목록에 "아직 차단에 쓰이지 않아요" 고지
- [ ] 안전 브라우저: 실제 웹 안 열림 (외부 링크 0) + 매치 시 잠깐 멈춤으로 연결 + 무매치도 정직 카피
- [ ] 확장 안내: Chrome 데스크톱 한정·모바일/SNS/모자이크 불가·관리형 PC 정책 제한·테스트 신호 전용 — 4한계 모두 명시
- [ ] 사용자 카피에 "프로토타입" 등 stage 어휘 0건 (R-3 회귀 감시)
- [ ] 차단(잠깐 멈춤) 페이지가 시도된 목적지를 절대 표시 안 함

## 9. 브라우저 스크린샷 리뷰 절차 (eyes 루프)

- [ ] 뷰포트 390×844 고정 (+ 가능하면 360×800 추가)
- [ ] 화면당 최소 1장, 스크롤 구간은 구간별 추가 (inner-scroll이라 fullPage 무효 — `main` 스크롤 조작)
- [ ] 시트·오버레이는 **열린 상태**로 별도 1장
- [ ] 저장 규칙: `references/visual-qa/<날짜>/qa-NN-<이름>.png` — 리뷰 문서에서 파일명 인용
- [ ] 각 샷에서 3질문: ① 탭해 보이는데 안 되는 것? ② 안 보이는데 실제론 되는 것? ③ 화면이 약속하는데 코드가 못 지키는 문장?
- [ ] 환경 한계를 결과에 명기 (폰트 대체·이모지 토푸·오디오 미검증 등) — 한계 숨기면 그 자체가 가짜 검증
- [ ] dev 전용 UI(화면 전환기, ?dev=1) 노출 여부 확인 — 제품 경로에 보이면 `[!]`
- [ ] 마지막 줄에 명시: "브라우저 실측 완료" 또는 "**브라우저 실측 불가 — 비주얼 QA 미검증**" 중 하나
