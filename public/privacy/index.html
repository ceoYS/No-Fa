NoF 실드 개인정보 처리방침

시행일: 2026년 10월 3일
대상: NoF 실드 Chrome 확장 프로그램

NoF 실드는 이 Chrome 브라우저에서 사용자가 직접 확인한 위험 신호에 잠깐 멈춤이라는 마찰을 더하는 도구입니다. 방문 기록이나 차단한 주소를 NoF 서버로 보내지 않습니다.

1. 수집하는 정보

NoF 실드는 사용자의 방문 기록, 방문 주소, 검색어, 쿠키 또는 페이지 내용을 서버로 수집하지 않습니다. 확장 프로그램에는 광고, 분석 도구, 원격 코드 실행 또는 방문 기록 전송 기능이 없습니다.

2. 차단 대상 정보

사용자가 NoF 웹앱에서 직접 확인한 구체적인 차단 값은 Chrome의 declarativeNetRequest 규칙으로 이 브라우저 안에서만 처리될 수 있습니다.

차단 화면은 사용자가 어디로 이동하려 했는지 읽거나 표시하거나 NoF 서버에 전송하지 않습니다.

3. NoF 웹앱과 확장 프로그램 사이의 데이터

NoF 웹앱은 사용자가 직접 확인한 구체 값만 확장 프로그램에 전달할 수 있습니다. 사용자가 작성한 상황 메모 자체를 브라우저 차단 규칙으로 전송하지 않습니다.

확장 프로그램에서 NoF 앱으로 돌아갈 때는 from=shield 및 to=record 또는 to=urge와 같은 일반적인 이동 목적만 사용하며, 차단된 주소나 검색어를 전달하지 않습니다.

4. 데이터 판매 및 제3자 공유

NoF 실드는 사용자의 브라우징 데이터를 판매하지 않으며, 광고 목적으로 제3자에게 제공하지 않습니다.

5. Chrome 권한

NoF 실드는 차단 규칙을 적용하기 위해 declarativeNetRequest 권한을 사용합니다.

사용자가 지정한 위험 신호는 어느 웹사이트의 최상위 이동에서도 나타날 수 있기 때문에 차단 규칙이 웹 전반의 탐색에 적용될 수 있도록 HTTP/HTTPS 호스트 범위를 사용합니다. 이 권한을 이용해 페이지 내용을 읽거나 스크립트를 삽입하지 않으며, 쿠키·브라우징 기록·탭 내용을 서버로 수집하지 않습니다.

6. 기능의 범위와 한계

  • NoF 실드는 Chrome 데스크톱 브라우저 안에서만 작동합니다.
  • 기기 전체, 다른 앱, iOS 또는 Android 전체를 차단하지 않습니다.
  • 위험한 주소를 AI가 자동으로 판단하거나 자동 분류하지 않습니다.
  • 확장을 끄거나 다른 브라우저를 사용하면 우회할 수 있습니다.
  • 의학적 치료나 진단을 제공하는 서비스가 아닙니다.
